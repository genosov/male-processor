# Excel-отчёт обработки почты

Расширение `analytics_report` создаёт простой Excel-отчёт по результатам
обработки корпоративной почты.

По умолчанию файл сохраняется в:

```text
reports/processing_report.xlsx
```

Отчёт строится на основе объекта `ProcessingStats`, который возвращает основной
пайплайн, и структуры папок `data/processed/<category>`.

## Листы отчёта

### Summary

Сводка по запуску:

- дата отчёта;
- всего файлов;
- обработано успешно;
- ошибок;
- процент успешности;
- файлов в архиве.

### Categories

Количество обработанных файлов по категориям на основе архива
`data/processed/<category>`.

- critical;
- support;
- business;
- info;
- spam;
- unknown;
- corrupted.

### ProcessedFiles

Список файлов из папок `data/processed/<category>`.

Для каждого файла расширение вызывает `FileHandler.get_file_metadata(file_path)`
и записывает:

- название файла;
- категорию;
- размер в байтах;
- расширение;
- дату создания;
- дату изменения;
- полный путь.

Даты в отчёте выводятся в формате `YYYY-MM-DD HH:MM:SS`.
