# male-processor
Mail-processor — это проект для автоматической обработки входящих писем. Он последовательно считывает содержимое файлов, извлекает из них основные данные, определяет категорию письма и сохраняет результат обработки.

## Возможности приложения
- Чтение писем, находящихся в файлах
- Извлечение основных данных: имя отправителя, темы, основного текста
- Классифицирование писем
- Сохранение обработанных писем;
- Логирование работы приложения;
- Тестирование основных компонентов проекта.

## Как работает приложение
Общий процесс обработки письма выглядит так:
1. Программа берет файл из папки `data/inbox/`.
2. Парсер читает содержимое файла и извлекает основные данные письма. 
3. Классификатор определяет категорию письма.
4. Обработанное письмо сохраняется в папку `data/processed/`.
5. Информация о работе приложения записывается в логи.

## Категории

Сейчас классификатор использует следующие категории:

- `critical` - критические инциденты, которые требуют быстрой реакции.
- `spam` - рекламные, подозрительные или низкоприоритетные письма.
- `support` - обращения пользователей в поддержку и IT-проблемы.
- `business` - деловая переписка: договоры, счета, встречи, клиенты и оплаты.
- `info` - информационные письма: уведомления, отчёты, обновления и напоминания.
- `unknown` - письма, которые удалось прочитать, но не удалось отнести ни к
  одной из настроенных категорий.

Категория `corrupted` не назначается самим классификатором. Она относится к
уровню чтения и разбора файлов: если файл нельзя прочитать, декодировать или
преобразовать в объект письма, такая ситуация должна обрабатываться до этапа
классификации. Поэтому отсутствие возврата `corrupted` из `EmailClassifier` -
это намеренное архитектурное решение, а не пропущенная категория.

## Запуск приложения

Для запуска проекта нужно перейти в корневую папку проекта и запустить следующие команды:

rm -rf data/inbox data/processed
unzip inbox.zip -d data
./run.sh
